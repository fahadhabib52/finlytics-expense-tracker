# Finlytics – Expense Tracker

Finlytics is a web-based expense tracker designed to help users manage their personal finances in one place.

## 🚀 Live Demo

**[Open Finlytics](https://expencetracker56.infinityfree.me/)**

## ✨ Features

- Track daily expenses
- Record income
- Manage budgets
- Track money lent and borrowed
- Record received payments
- View financial summaries
- User authentication
- Responsive web interface

## 🛠️ Technologies

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap

## 🎯 Purpose

Finlytics was built as a practical personal finance management application for tracking income, expenses, budgets and money-related records through a simple web interface.
